# LoKo.i 웹사이트

부산 여행자와 현지인을 연결하는 LoKo.i의 공식 웹사이트입니다. 영어, 번체 중국어(대만), 한국어를 지원합니다.

| 페이지 | 내용 |
|---|---|
| `index.html` | 홈: 서비스 소개, 이용 방법, 활동, 로컬 팁, 안전 수칙, FAQ |
| `apply.html` | 여행자 신청서 |
| `local.html` | 현지인 등록 신청서 |
| `privacy.html` | 개인정보 처리방침 |
| `activities.html` | 활동별 로컬 추천 (6개 분야, 18곳) |
| `admin/index.html` | 매칭 관리 화면 (관리자 키로 시트를 불러와 추천 배정안) · `?demo=1`로 예시 보기 |
| `assets/match.js` | 매칭 엔진 (언어·성별 조건 + 활동·지역·시간·언어 수준 점수) · 테스트 `node tests/match.test.js` |
| `board.html` | 여행자 게시판 (신원 확인된 현지인 전용 개인 링크, 자동 번역) · `?demo=1`로 예시 보기 |
| `dm-agent/` | 인스타 DM 다국어 AI 자동 응대 서버 (자세한 내용은 `dm-agent/README.md`) |

신청서 내용은 구글 시트에 저장됩니다. 서버 비용은 0원입니다.

## 지금 상태 (2026-11-18)

사이트·신청서·시트·매칭 화면 모두 연결 완료. 아래 링크만 공유하면 바로 신청을 받을 수 있어요.

| 용도 | 링크 |
|---|---|
| 홈 (인스타 프로필) | https://lokoikr.github.io/ |
| 여행자 신청 · 영어 | https://lokoikr.github.io/apply.html?lang=en |
| 여행자 신청 · 대만 | https://lokoikr.github.io/apply.html?lang=zh |
| 현지인 등록 · 한국어 | https://lokoikr.github.io/local.html?lang=ko |

링크를 카톡·인스타에 붙이면 미리보기 이미지(`assets/img/og.jpg`, 현지인용 `og-local.jpg`)가 떠요.

사진: 신청자가 올린 사진은 구글 드라이브 `LoKo.i 신청 사진` 폴더에 저장되고, 시트에는 파일 ID(`photo_id`)만 남아요. 매칭 관리 화면에서 관리자 키를 넣으면 사진과 '신청자 점검'(정상/확인 필요/의심)이 함께 보여요.

운영 순서: 시트에 `신규`로 쌓임 → 현지인은 영상통화·신분 확인 후 `확인 완료` → 매칭 화면에서 추천안 확인 → 연결 후 `연결 완료`(다음 매칭에서 자동 제외).

## 1. 사이트 공개하기 (GitHub Pages)

1. 이 저장소의 **Settings › Pages**로 갑니다.
2. Source를 **Deploy from a branch**로 두고, Branch를 **main**, 폴더를 **/ (root)**로 고른 뒤 Save를 누릅니다.
3. 1~2분 뒤 `https://lokoikr.github.io/` 에서 사이트가 열립니다.

## 2. 신청서 연결하기 (구글 시트)

1. 구글 드라이브에서 새 구글 시트를 만들고 이름을 `LoKo.i 웹 신청`으로 정합니다.
2. 시트 메뉴 **확장 프로그램 › Apps Script**를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여 넣습니다. 알림 메일을 받으려면 맨 위 `NOTIFY_EMAIL`에 주소를 넣습니다.
4. 저장한 뒤 함수 목록에서 `setup`을 골라 **실행**합니다. 권한 요청이 나오면 본인 계정으로 허용합니다. 시트에 `여행자 신청`, `현지인 등록` 탭이 생기면 성공입니다.
5. **배포 › 새 배포 › 유형 선택: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
7. 이 저장소의 `assets/config.js`를 열어 `ENDPOINT: ""` 따옴표 안에 붙여 넣고 커밋합니다.

8. `setup`을 실행할 때 실행 기록(로그)에 **매칭 관리 화면 키**가 찍힙니다. 이 키를 `admin/` 화면에 넣으면 시트의 신청을 바로 불러와 매칭해요. 키는 다른 사람에게 알려 주지 마세요.

이후 사이트에서 신청하면 시트에 한 줄씩 쌓입니다. `status` 열은 `신규`로 들어오니, 연결을 마치면 `연결 완료` 등으로 바꿔 관리하세요.

## 3. 자주 바꾸는 곳

- 문구: 영어는 각 HTML 파일, 번체와 한국어는 `assets/i18n.js`
- 사진: `assets/img/`
- 색상과 글꼴: `assets/style.css` 맨 위
- 문의 이메일: `assets/config.js`의 `CONTACT_EMAIL`

언어는 브라우저 설정에 맞춰 자동으로 바뀌고, 오른쪽 위에서 직접 고를 수도 있습니다. 링크 끝에 `?lang=zh` 또는 `?lang=ko`를 붙이면 해당 언어로 열립니다.
