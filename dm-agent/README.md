# LoKo.i 인스타 DM 다국어 자동 응대

인스타그램 DM이 오면 영어·번체 중국어·한국어·일본어 중 보낸 사람의 언어로 AI가 답합니다. 신고·위급·데이트 목적·환불 같은 메시지는 AI가 답하지 않고 담당자에게 넘깁니다.

```
DM 도착 → 메타 웹훅 → 이 서버
  ├─ 위급(도와주세요·危險 등)  → 112·119 안내 + 담당자 알림
  ├─ 신고·데이트·돈 문제        → "담당자가 곧 답해요" + 담당자 알림
  └─ 일반 질문                  → Claude가 답변 (첫 대화엔 '자동 응답' 안내 붙임)
```

## 파일

| 파일 | 내용 |
|---|---|
| `server.js` | 웹훅 서버 (외부 패키지 없음, Node 18 이상) |
| `agent.js` | 언어 감지, 안전 분류, AI 호출, DM 보내기 |
| `knowledge.js` | AI에게 주는 LoKo.i 정보와 답변 규칙, 언어별 고정 문구 |
| `test.js` | 실제 API 없이 동작 확인 (`node dm-agent/test.js`) |

## 환경변수

| 이름 | 값 |
|---|---|
| `VERIFY_TOKEN` | 메타 웹훅 등록할 때 직접 정하는 아무 문자열 |
| `APP_SECRET` | 메타 개발자 앱 › 앱 설정 › 기본 설정 › 앱 시크릿 코드 |
| `IG_ACCESS_TOKEN` | 기존 자동 DM에서 쓰는 인스타그램 액세스 토큰 |
| `ANTHROPIC_API_KEY` | Claude API 키 (console.anthropic.com) |
| `ANTHROPIC_MODEL` | 비우면 `claude-haiku-5-5` (빠르고 저렴) |
| `NOTIFY_WEBHOOK_URL` | 선택. 담당자 알림을 받을 디스코드·슬랙 웹훅 주소 |
| `DRY_RUN` | `1`이면 답장을 보내지 않고 로그에만 남김 (시험용) |

## 연결 순서

1. 기존 자동 DM 서버와 같은 곳(Render)에 Web Service로 올립니다. 시작 명령: `node dm-agent/server.js`
2. 메타 개발자 앱 › Instagram › 웹훅에서 콜백 URL을 `https://<서버주소>/webhook`, 확인 토큰을 `VERIFY_TOKEN`과 같게 넣고 **messages** 필드를 구독합니다.
3. 권한 `instagram_business_manage_messages`가 있는지 확인합니다.
4. 처음 1~2일은 `DRY_RUN=1`로 로그만 보고 답변 품질을 확인한 뒤 끕니다.

## 댓글 → 링크 DM (선택)

게시물에 키워드(BUSAN, 부산, 釜山, link, 링크 등) 댓글이 달리면 그 사람에게 신청 링크를 DM으로 1번 보냅니다(인스타 '비공개 답장').

- 영어 댓글 → 영어 신청서, 중국어 → 대만어 신청서, 한국어 → 현지인 등록 링크
- 데이트·돈 관련 댓글은 링크 대신 담당자 알림만
- 같은 사람이 같은 게시물에 여러 번 달아도 1번만

추가 환경변수:

| 이름 | 값 |
|---|---|
| `COMMENT_DM` | `1`이면 켜짐 |
| `IG_USER_ID` | 우리 인스타 계정 ID (내 댓글엔 반응하지 않게) |
| `PUBLIC_REPLY` | `1`이면 댓글에 "DM 보냈어요 📩"도 공개로 답함 |
| `COMMENT_KEYWORDS` | 키워드 바꾸기 (쉼표로 구분) |

메타 웹훅에서 **comments** 필드도 구독하고, 권한 `instagram_business_manage_comments`가 있어야 해요. 인스타 규칙상 댓글 1개당 DM 1번, 댓글 후 7일 안에만 보낼 수 있어요.

> 초기(댓글 월 25명 이하)에는 ManyChat 무료 요금제로 같은 기능을 서버 없이 쓸 수 있어요. 그보다 많아지면 이 서버로 옮기면 비용이 들지 않아요.

## 주의

- Render 무료 서버는 15분간 요청이 없으면 잠들어 첫 답장이 늦어요. 실제 운영은 유료 인스턴스(월 1만 원 안팎)를 권장해요.
- 메타 규정상 사용자가 마지막으로 보낸 메시지로부터 24시간 안에만 답할 수 있어요. 이 서버는 메시지가 오는 즉시 답하므로 문제없어요.
- AI 비용은 DM 수백 건 기준 월 몇천 원 수준이에요.
